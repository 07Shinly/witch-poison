# 🧙‍♀️ 女巫的毒药

一个单文件网页小游戏（家教/课堂双人互动）：**两人轮流翻开单词卡片并读出英文单词，卡片里藏着毒药，翻到毒药就“中毒”失败**。学生用手机/平板/电脑打开链接即可玩，无需安装。

## 玩法

1. 从单词表生成一组卡片，其中藏着 1～3 瓶“毒药”。
2. 两人轮流点开卡片，翻开后**大声读出英文单词**（限时内）；中文含义由老师/家长期现场听辨。
3. 普通单词：得分，轮到对方；**翻到毒药：立刻中毒，本局失败，对方获胜**。
4. 多局制，先赢下更多局者胜。

## 设置
- 单词自由录入（表格增删 / 批量粘贴 / 示例词库）
- 卡片数量、毒药数量、朗读限时、总局数、语音朗读
- 🎲 随机藏毒药，或 🧙‍♀️ 教师秘密指定毒药（开始前点选，学生别看屏幕）

## 在 GitHub 发布（手机可打开的链接）

1. 新建一个仓库（例如 `witch-poison`），点 **Add file → Upload files**。
2. 把本文件夹里的 **`index.html`**（和 `README.md`）上传到仓库根目录。
3. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` + `main`，点 Save。
4. 等 1～2 分钟，游戏链接为：

   `https://你的用户名.github.io/witch-poison/`

也可直接双击 `index.html` 在本地浏览器打开。

> 单文件网页，无任何外部依赖；上传 `index.html` 一个文件即可运行。
